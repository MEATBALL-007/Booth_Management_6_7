# Display Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the customer-facing Display screen: a read-only, fullscreen view of a booth's queue — a big "กำลังทำ / Now Serving" section (all serving numbers in parallel) and a "คิวถัดไป / Up Next" list — that plays a chime and flashes the screen for ~2.5s whenever a new order starts serving.

**Architecture:** Reuses the orders repository from Plan 2 (`subscribeBoothOrders`, already client-sorts by `createdAt`). Queue view derivation (serving list, up-next list, new-serving detection) is pure and unit-tested (`src/display/queueView.ts`). The chime is a thin Web Audio wrapper with an injectable context for testing (`src/display/chime.ts`). A small hook (`src/display/useServingAlert.ts`) turns "a new serving number appeared" into chime + a transient `flashing` flag. The `DisplayScreen` component composes these; App routes `display` mode to it.

**Tech Stack:** React 19, TypeScript, Tailwind (PHANTOM CREW), Web Audio API, Vitest + @testing-library/react (incl. `renderHook`, fake timers).

## Global Constraints

- **Builds on Foundation + Order Station (both merged to `main`).** Reuse `subscribeBoothOrders` from `src/order/ordersRepo.ts` (do NOT add new Firestore code — no direct `firebase/firestore` import in Display). Reuse `Order`/`BoothId` types, `L`/`BiLabel`.
- **Optimistic / offline-first:** Display is read-only; it only subscribes. Never await anything for rendering. `subscribeBoothOrders` already delivers orders sorted by `createdAt` ascending (client-side, no composite index) — do not re-introduce a Firestore `orderBy`.
- **Display is booth-level, not station-level:** it shows ALL stations' queues for the booth (customers read one screen; numbers are station-prefixed like `A7`/`B3`). Display mode needs no station (Setup already makes station optional for non-order modes).
- **Now Serving is parallel:** multiple `serving` orders shown at once (drawing booth has 5 artists serving in parallel).
- **Alert on new serving:** when a queueNumber newly enters the serving set, play a chime (Web Audio) and flash the screen ~2.5s. The first snapshot after mount is the baseline (no alert for pre-existing serving orders).
- **Bilingual:** labels via `L` showing Thai + English. **Theme:** PHANTOM CREW; queue numbers big + `font-mono`, readable from far away.
- **Testing:** Vitest. Pure logic → unit tests. Chime → test with a mocked AudioContext (never create a real one in tests). Hook → `renderHook` + fake timers, chime mocked. Component → @testing-library/react with the repo + chime mocked. Use the repo's `vi.hoisted(() => ({...}))` convention for mock spies referenced inside `vi.mock`. Run `npm run build` (`tsc -b`) as well as `npm test`. Commit after each task.

import type { Order } from '../domain/types'

export function servingOrders(orders: Order[]): Order[] {
  return orders.filter((o) => o.status === 'serving')
}

export function upNextOrders(orders: Order[]): Order[] {
  return orders.filter((o) => o.status === 'waiting').sort((a, b) => a.createdAt - b.createdAt)
}

export function newlyServing(prev: string[], next: string[]): string[] {
  const seen = new Set(prev)
  return next.filter((n) => !seen.has(n))
}
```

export function playChime(makeCtx: () => AudioContext = () => new AudioContext()): void {
  const ctx = makeCtx()
  const osc = ctx.createOscillator()
  const gain = ctx.createGain()
  osc.type = 'sine'
  osc.frequency.value = 880
  gain.gain.value = 0.2
  osc.connect(gain)
  gain.connect(ctx.destination)
  osc.start()
  osc.stop(ctx.currentTime + 0.25)
}
```

- [ ] **Step 3: Create `src/display/useServingAlert.ts`**

```ts
import { useEffect, useRef, useState } from 'react'
import { newlyServing } from './queueView'
import { playChime } from './chime'

const FLASH_MS = 2500

export function useServingAlert(servingNumbers: string[]): boolean {
  const prev = useRef<string[]>(servingNumbers)
  const first = useRef(true)
  const [flashing, setFlashing] = useState(false)
  const key = servingNumbers.join('|')

  useEffect(() => {
    if (first.current) {
      first.current = false
      prev.current = servingNumbers
      return
    }
    const fresh = newlyServing(prev.current, servingNumbers)
    prev.current = servingNumbers
    if (fresh.length > 0) {
      playChime()
      setFlashing(true)
      const t = setTimeout(() => setFlashing(false), FLASH_MS)
      return () => clearTimeout(t)
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [key])

  return flashing
}
```

```tsx
import { useEffect, useState } from 'react'
import type { BoothId, Order } from '../domain/types'
import { subscribeBoothOrders } from '../order/ordersRepo'
import { servingOrders, upNextOrders } from '../display/queueView'
import { useServingAlert } from '../display/useServingAlert'
import { L } from '../i18n/labels'

export function DisplayScreen({ booth }: { booth: BoothId }) {
  const [orders, setOrders] = useState<Order[]>([])
  useEffect(() => subscribeBoothOrders(booth, setOrders), [booth])

  const serving = servingOrders(orders)
  const upNext = upNextOrders(orders)
  const flashing = useServingAlert(serving.map((s) => s.queueNumber))

  return (
    <div
      className={`min-h-screen p-8 flex flex-col gap-10 transition-colors ${
        flashing ? 'bg-phantom-orange/30 animate-pulse' : 'bg-phantom-bg'
      }`}
    >
      <header className="flex items-center justify-between">
        <span className="font-kanit text-3xl text-phantom-yellow">
          {L(`booth.${booth}`).th} · {L(`booth.${booth}`).en}
        </span>
      </header>

      <section>
        <h2 className="font-kanit text-2xl opacity-80 mb-4">
          {L('display.nowServing').th} · {L('display.nowServing').en}
        </h2>
        {serving.length === 0 ? (
          <p className="font-kanit text-xl opacity-50">
            {L('display.noQueue').th} · {L('display.noQueue').en}
          </p>
        ) : (
          <div className="flex flex-wrap gap-8">
            {serving.map((s) => (
              <div key={s.id} data-testid="serving" className="font-mono text-8xl text-phantom-orange">
                {s.queueNumber}
              </div>
            ))}
          </div>
        )}
      </section>

      <section>
        <h2 className="font-kanit text-2xl opacity-80 mb-4">
          {L('display.upNext').th} · {L('display.upNext').en}
        </h2>
        <div className="flex flex-wrap gap-5">
          {upNext.map((u) => (
            <div key={u.id} data-testid="upnext" className="font-mono text-5xl opacity-80">
              {u.queueNumber}
            </div>
          ))}
        </div>
      </section>
    </div>
  )
}
```

import { useState } from 'react'
import { SetupScreen } from './screens/SetupScreen'
