# HQ + Inter-Booth Comms Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let booths and HQ talk during the event: each Order Station can fire a preset alert (🆘 need help / 📦 low stock / ✅ cleared) or a short text; HQ (the Dashboard on a PC) can broadcast to everyone and see a live presence board of which devices are online. Alerts pop as a toast (with acknowledge) on Order Stations and the Dashboard — **never** on the customer-facing Display.

**Architecture:** Two new Firestore collections at the edges (`messages`, `presence`) behind a single `src/comms/commsRepo.ts`. A stable per-device id (localStorage) identifies senders and ack-ers. Presence liveness and toast selection are **pure functions** (unit-tested, no Firebase). A heartbeat hook writes presence on an interval. Small components (AlertButtons, CommsToast, PresenceBoard, BroadcastBar) compose these and are wired into OrderStation (send + receive) and DashboardScreen/HQ (broadcast + presence + receive). Firestore stays at the edges; everything else is pure/testable.

**Tech Stack:** React 19, TypeScript, Tailwind (PHANTOM CREW), Firebase Firestore (via `commsRepo`), Vitest + @testing-library/react (renderHook, fake timers).

## Global Constraints

- **Builds on Plans 1–4 (all merged to `main`).** Reuse `getDb()` (`src/lib/firebase.ts`), `BoothId`/`Mode`/`Station`/`BOOTH_IDS` (`src/domain/types.ts`), `DeviceConfig`/`loadDeviceConfig` (`src/device/deviceConfig.ts`), `L` (`src/i18n/labels.ts`). Do NOT reimplement.
- **Firestore only at the edges:** only `src/comms/commsRepo.ts` imports `firebase/firestore`. Types, presence logic, toast selection, hooks, and components import no Firestore.
- **No composite index:** `subscribeMessages`/`subscribePresence` are single-collection `onSnapshot`, sorted client-side (no `where`+`orderBy`).
- **Optimistic writes:** `sendMessage`/`ackMessage`/`upsertPresence` are fire-and-don't-await for the UI (Firestore persistence queues offline). Surface send failures with a visible error where the user initiated the send (mirror the OrderStation/Dashboard `.catch(setError)` + `role="alert"` convention).
- **Comms visibility (locked):** the alert toast and send controls appear on **Order Station** and the **Dashboard/HQ** only. The customer-facing **Display shows NOTHING** from comms.
- **HQ is the Dashboard (locked):** no new mode. HQ panels (presence board, broadcast bar) are added to `DashboardScreen` (shown once unlocked). The two HQ PCs both run Dashboard mode and are interchangeable.
- **Message model:** `kind: 'alert' | 'text' | 'broadcast'`; alerts carry `presetCode: 'need_help' | 'low_stock' | 'cleared'`; broadcast = from HQ. `scope: 'all' | BoothId`. Toast shows a message iff `(scope === 'all' || scope === myBooth) && fromDeviceId !== myDeviceId && !ackBy.includes(myDeviceId)`.
- **Presence:** heartbeat every 30s; a device is online iff `now − lastSeen < 90000ms`.
- **Bilingual** labels via `L` (Thai + English). **Theme** PHANTOM CREW.
- **Testing:** Vitest. Pure logic (`presence`, toast selection, deviceId) → unit tests. `commsRepo` → `vi.hoisted` + mocked `firebase/firestore` + mocked `../lib/firebase` (as in `ordersRepo.test.ts`). Hook → `renderHook` + fake timers + mocked repo. Components → mock `../comms/commsRepo` and drive via a captured `emit`. Add only the labels a task uses (avoid dumping all labels in one task). Run `npm run build` (`tsc -b`) as well as `npm test`. Commit after each task.

```ts
const KEY = 'phantom.deviceId'

export function getDeviceId(): string {
  const existing = localStorage.getItem(KEY)
  if (existing) return existing
  const id = crypto.randomUUID()
  localStorage.setItem(KEY, id)
  return id
}
```

```ts
import type { Message, Presence } from './types'
import type { BoothId } from '../domain/types'

const ONLINE_THRESHOLD_MS = 90_000

export function isOnline(p: Presence, now: number, thresholdMs: number = ONLINE_THRESHOLD_MS): boolean {
  return now - p.lastSeen < thresholdMs
}

export function visibleMessages(messages: Message[], myBooth: BoothId, myDeviceId: string): Message[] {
  return messages
    .filter((msg) => (msg.scope === 'all' || msg.scope === myBooth))
    .filter((msg) => msg.fromDeviceId !== myDeviceId)
    .filter((msg) => !msg.ackBy.includes(myDeviceId))
    .sort((a, b) => b.createdAt - a.createdAt)
}
```

```ts
import { collection, addDoc, onSnapshot, doc, updateDoc, setDoc, arrayUnion } from 'firebase/firestore'
import { getDb } from '../lib/firebase'
import type { Message, Presence } from './types'

export async function sendMessage(msg: Omit<Message, 'id'>): Promise<string> {
  const ref = await addDoc(collection(getDb(), 'messages'), msg)
  return ref.id
}

export function subscribeMessages(cb: (messages: Message[]) => void): () => void {
  return onSnapshot(collection(getDb(), 'messages'), (snap) => {
    const messages = snap.docs.map((d) => ({ id: d.id, ...(d.data() as Omit<Message, 'id'>) }))
    cb(messages.sort((a, b) => a.createdAt - b.createdAt))
  })
}

export async function ackMessage(id: string, deviceId: string): Promise<void> {
  await updateDoc(doc(getDb(), 'messages', id), { ackBy: arrayUnion(deviceId) })
}

export async function upsertPresence(p: Presence): Promise<void> {
  await setDoc(doc(getDb(), 'presence', p.id), p, { merge: true })
}

export function subscribePresence(cb: (presence: Presence[]) => void): () => void {
  return onSnapshot(collection(getDb(), 'presence'), (snap) => {
    cb(snap.docs.map((d) => ({ id: d.id, ...(d.data() as Omit<Presence, 'id'>) })))
  })
}
```

```ts
import { useEffect } from 'react'
import { upsertPresence } from './commsRepo'
import type { Presence } from './types'

const HEARTBEAT_MS = 30_000

export function useHeartbeat(presence: Omit<Presence, 'lastSeen'> | null): void {
  const key = presence ? `${presence.id}|${presence.booth}|${presence.mode}|${presence.station ?? ''}` : null

  useEffect(() => {
    if (!presence) return
    const beat = () => { upsertPresence({ ...presence, lastSeen: Date.now() }) }
    beat()
    const timer = setInterval(beat, HEARTBEAT_MS)
    return () => clearInterval(timer)
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [key])
}
```

```tsx
import { useState } from 'react'
import type { BoothId, Mode } from '../domain/types'
import type { PresetCode, Message } from './types'
import { sendMessage } from './commsRepo'
import { getDeviceId } from '../device/deviceId'
import { L } from '../i18n/labels'

const PRESETS: { code: PresetCode; labelKey: 'comms.needHelp' | 'comms.lowStock' | 'comms.cleared'; icon: string }[] = [
  { code: 'need_help', labelKey: 'comms.needHelp', icon: '🆘' },
  { code: 'low_stock', labelKey: 'comms.lowStock', icon: '📦' },
  { code: 'cleared', labelKey: 'comms.cleared', icon: '✅' },
]

export function AlertButtons({ booth, mode }: { booth: BoothId; mode: Mode }) {
  const [text, setText] = useState('')
  const [error, setError] = useState(false)

  const base = () => ({
    fromDeviceId: getDeviceId(), fromBooth: booth, fromMode: mode,
    scope: 'all' as const, createdAt: Date.now(), ackBy: [] as string[],
  })

  const fire = (msg: Omit<Message, 'id'>) => {
    setError(false)
    sendMessage(msg).catch(() => setError(true))
  }

  return (
    <div className="flex flex-col gap-2">
      <div className="flex flex-wrap gap-2">
        {PRESETS.map((p) => (
          <button key={p.code} onClick={() => fire({ ...base(), kind: 'alert', presetCode: p.code })}
            className="rounded-lg px-3 py-2 bg-white/10 font-kanit">
            {p.icon} {L(p.labelKey).th}
          </button>
        ))}
      </div>
      <div className="flex gap-2">
        <input value={text} onChange={(e) => setText(e.target.value)} aria-label={L('comms.message').th}
          className="flex-1 rounded bg-black/40 px-2 py-2 text-white" />
        <button onClick={() => { if (text.trim()) { fire({ ...base(), kind: 'text', text: text.trim() }); setText('') } }}
          className="rounded-lg px-4 py-2 bg-phantom-yellow text-phantom-bg font-kanit">
          {L('comms.send').th}
        </button>
      </div>
      {error && <p role="alert" className="text-red-400 font-kanit text-sm">{L('comms.sendError').th} · {L('comms.sendError').en}</p>}
    </div>
  )
}
```

```tsx
import { useEffect, useState } from 'react'
import type { BoothId } from '../domain/types'
import type { Message, PresetCode } from './types'
import { subscribeMessages, ackMessage } from './commsRepo'
import { getDeviceId } from '../device/deviceId'
import { visibleMessages } from './commsLogic'
import { L } from '../i18n/labels'

const PRESET_LABEL: Record<PresetCode, 'comms.needHelp' | 'comms.lowStock' | 'comms.cleared'> = {
  need_help: 'comms.needHelp',
  low_stock: 'comms.lowStock',
  cleared: 'comms.cleared',
}

function body(msg: Message): string {
  if (msg.kind === 'broadcast') return `${L('comms.broadcast').th}: ${msg.text ?? ''}`
  if (msg.kind === 'alert' && msg.presetCode) return L(PRESET_LABEL[msg.presetCode]).th
  return msg.text ?? ''
}

export function CommsToast({ booth }: { booth: BoothId }) {
  const [messages, setMessages] = useState<Message[]>([])
  const me = getDeviceId()

  useEffect(() => subscribeMessages(setMessages), [])

  const top = visibleMessages(messages, booth, me)[0]
  if (!top) return null

  return (
    <div role="status" className="fixed top-3 left-1/2 -translate-x-1/2 z-50 rounded-xl bg-phantom-orange px-4 py-3 flex items-center gap-3 shadow-lg">
      <span className="font-kanit">
        {L(`booth.${top.fromBooth}`).th} · {body(top)}
      </span>
      <button onClick={() => ackMessage(top.id, me)} className="rounded bg-black/30 px-3 py-1 font-kanit">
        {L('comms.ack').th}
      </button>
    </div>
  )
}
```

```tsx
import { useState } from 'react'
import type { BoothId } from '../domain/types'
import { sendMessage } from './commsRepo'
import { getDeviceId } from '../device/deviceId'
import { L } from '../i18n/labels'

export function BroadcastBar({ booth }: { booth: BoothId }) {
  const [text, setText] = useState('')
  const [error, setError] = useState(false)

  const send = () => {
    if (!text.trim()) return
    setError(false)
    sendMessage({
      fromDeviceId: getDeviceId(), fromBooth: booth, fromMode: 'dashboard',
      scope: 'all', kind: 'broadcast', text: text.trim(), createdAt: Date.now(), ackBy: [],
    }).catch(() => setError(true))
    setText('')
  }

  return (
    <section className="flex flex-col gap-2 max-w-md">
      <h2 className="font-kanit opacity-80">{L('comms.broadcastSend').th} · {L('comms.broadcastSend').en}</h2>
      <div className="flex gap-2">
        <input value={text} onChange={(e) => setText(e.target.value)} aria-label={L('comms.broadcastSend').th}
          className="flex-1 rounded bg-black/40 px-2 py-2 text-white" />
        <button onClick={send} className="rounded-lg px-4 py-2 bg-phantom-yellow text-phantom-bg font-kanit">
          {L('comms.send').th}
        </button>
      </div>
      {error && <p role="alert" className="text-red-400 font-kanit text-sm">{L('comms.sendError').th}</p>}
    </section>
  )
}
```
