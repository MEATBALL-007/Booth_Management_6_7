3 ซุ้มขายของบริจาค + ระบบแอปของเราเอง

ห้องเราจะเปิด 3 ซุ้มขายของ รายได้เข้าเงินบริจาค — และมี "ระบบแอป" ที่เพื่อนในห้องทำขึ้นเอง ช่วยจัดการคิว รับเงิน และสรุปบัญชีแบบเรียลไทม์ ใช้ง่ายแค่เปิดเว็บ

งานนี้คืออะไร (สรุปสั้น)

เราแบ่งกันเป็น 3 ซุ้ม + ทีมบัญชี รวม 36 คน · ลูกค้าสั่งของ → จ่ายเงินสดหรือสแกน QR → รับเลขคิว → รอเรียกที่จอแสดงคิว → รับของ · ทุกออเดอร์เข้าระบบอัตโนมัติ → ยอดบริจาคสุทธิคำนวณให้เอง ตรวจสอบได้ทุกบาท
