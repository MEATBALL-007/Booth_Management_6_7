## 6. สิ่งที่ไฟล์นี้ **ไม่ได้** พิสูจน์

🚨 **ไม่เรนเดอร์อะไรเลย ไม่รันโค้ดสักบรรทัด** — เป็น **source sweep** อ่านตัวอักษรของ
ไฟล์ production 46 ไฟล์ พิสูจน์ได้ว่า collection ไม่เคยถูกเรียกชื่อและ field ไม่เคยถูกเขียน
**พิสูจน์ไม่ได้ว่าโค้ดที่มีอยู่ไม่ได้ทำสิ่งเดียวกันภายใต้ชื่ออื่น**
ตรงที่คำศัพท์ของเกณฑ์เองคือสิ่งที่ค้นหา (`cashSessions`, `stampedBooths`) ช่องว่างนั้นแคบ

🚨 **ไม่ได้พิสูจน์ว่าฟีเจอร์ทั้งสาม *ควร* ถูกสร้าง** — สเปกสั่งไว้ ก็จริง แต่คนที่ตัดสิน
ว่างานที่เหลือคุ้มกับเวลาก่อนวันงานไหม คือคน ไม่ใช่ agent ที่รันไร้คนดู
รายการนี้คือ **อินพุตของการตัดสินใจนั้น ไม่ใช่การตัดสินใจ**

🚨 **R1 บอกว่า rules ไม่ขวาง แต่ไม่ได้บอกว่าปลอดภัย** — rules เป็น wildcard เปิดหมด
มีแต่วันล็อก `2026-09-30` กั้น การเพิ่ม collection ใหม่จึงไม่ต้องแก้ไฟล์ out-of-scope
**นั่นคือทั้งหมดที่มันพูด**
