## 1. เปลี่ยนจาก "วัดข้อต่อทีละคู่" เป็น "วัดทุกปลายเทียบ HEAD"

รอบก่อนๆ วัดแบบโซ่: `_0019` เทียบ `_0006` · `_0006` เทียบ `_0155` · … ต่อกันไปเรื่อยๆ
วิธีนั้นเสียหนึ่งดิฟฟ์ต่อหนึ่งข้อต่อ และ **ยาวเท่าที่คนรอบนั้นมีแรงไล่**

รอบนี้เทียบ **ทุกปลาย branch เทียบกับ HEAD ตัวเดียว** ด้วยขอบเขตเดิม
(ทุก path ยกเว้น `AUTOPILOT.md` / `SUMMARY.md`):

```
git diff --name-only HEAD <tip> -- . ':(exclude)AUTOPILOT.md' ':(exclude)SUMMARY.md'
```

**ความเท่ากันเป็น transitive** — ถ้า `A == HEAD` และ `B == HEAD` แล้ว `A == B` โดยอัตโนมัติ
➡️ การวัด 23 ครั้งเทียบจุดอ้างอิงเดียว **พิสูจน์ได้มากกว่า** การวัด 23 ข้อต่อแบบต่อกันเป็นโซ่
และ **ไม่มีชั้นไหนเป็นการเชื่อบันทึกของรอบก่อน**
